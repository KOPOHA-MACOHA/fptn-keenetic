# Панель и служба 0.18.13

Исправлен первый запуск при заранее установленном штатном lighttpd. Если
нет работающего процесса, конфиг совпадает с пакетом opkg и основной порт
равен 80 (в том числе не указан явно), bootstrap создаёт локальный служебный
listener. Это устраняет конфликт с веб-интерфейсом Keenetic. Пользовательский
основной конфиг, другой основной порт и работающий сервер не перенастраиваются.

Локальные проверки страницы/API и смены порта игнорируют пользовательский
curlrc. При сбое ошибка curl выводится в самой установке и сохраняется до отката.
Обязательные проверки версии, доступа и PHP не отключаются.

Сценарий конфликта первичного listener воспроизведён на настоящем lighttpd;
после выполнения реального bootstrap-блока панель отвечает HTTP 200.
Тест также проверяет реальные HTTP/API-запросы с curlrc, запрещающим HTTP.
Клиент 0.8.1 и его зависимости не пересобираются.
