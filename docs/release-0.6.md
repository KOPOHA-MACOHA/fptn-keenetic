# Вход в панель 0.6.0

- Установщик больше не запрашивает логин или пароль в терминале.
- Первый экран в браузере: создать учётную запись, подтвердить пароль и войти.
- Альтернатива: существующий root Entware через PHP crypt, как nfqws-keenetic-web.
  Читается /opt/etc/shadow или, если его нет, /opt/etc/passwd. Пользователи и их
  пароли не меняются, пароль root не копируется в конфигурацию FPTN.
- Уже установленный php-cgi выполняет проверку. Отдельный openssl не нужен.
- Новый отдельный пароль хранится bcrypt/cost10, принимается непустой до 72 байт.
- Первый setup выполняется один раз под flock; конкурентный запрос не заменяет
  уже созданную учётную запись. Cookie-аутентификации нет; сохраняются Host/Origin
  и ограничения запросов API. Сессии имеют срок и отзыв при выходе/смене пароля.
- Настройки входа 0.5.0 поддерживаются без пересоздания и без openssl.
- Восстановление доступа: fptnctl web-reset-login (root), затем открыть браузер.
- Клиент остаётся 0.4.0; пересборка зависимостей не требуется. Сохранены исправления
  обновления, native-маршрутизация и управление автозапуском версии 0.5.

Проверки: настоящий app.js в DOM-подмене, транзакция установщика и его откат;
PHP CLI/CGI в CI проверяет создание/вход/root/сессии/ограничения/конкурентный setup.
PHP устанавливается только на временный CI runner, не на роутер. На роутере
повторно используется уже имеющийся php-cgi. Итог CI и проверку устройства
следует различать: установка на Hopper остаётся отдельной проверкой.

Остальные задачи поддерживаемого выпуска перечислены в [плане 0.5](release-0.5.md).
