# Панель и native-служба 0.5.0

Использует опубликованный клиент 0.4.0 без изменения протокола/зависимостей.
Переход с клиента 0.2.0 включает скачивание готового проверенного бинарника.

Изменено:
- guarded stop учитывает канонический USB-путь /opt, осиротевший клиент,
  заменённый ELF и зависший supervisor. Принудительная остановка только
  после проверки PID, boot-id, времени старта и принадлежности процесса.
- обновление файлов с резервной копией и откатом; первый отказ остановки
  прекращает установку до замены файлов. Есть регрессии с отказами на rename/restart.
- вход по отдельному логину/паролю; crypt SHA-512, сессии с отзывом/истечением,
  ограничение попыток; прежний код не принимается.
- управление автозапуском из панели; загрузка не ждёт сети и READY, supervisor
  повторяет начальное подключение с ограниченной паузой. Отключение не рвёт туннель.
- UI/controller-only изменения проходят host-проверки отдельно от C++ сборки.
  Маркер [runtime-only] пропускает C++ jobs для такого push; ручной запуск
  Build prototype остаётся доступен и выполняет полную сборку.

Проверка на устройстве после установки: версии 0.5.0/0.4.0, вход/выход,
start/stop/restart, прежний VPN IP через маршруты Keenetic, повторное обновление,
автозапуск после сохранения интерфейса и перезагрузки по инициативе пользователя.
Результаты CI не заменяют аппаратных испытаний целевой платформы.

Текущие возможности и ограничения: [сравнение с оригинальным FPTN](feature-parity.md).

Это native-интеграция Keenetic; маршруты, DNS и firewall остаются штатными.
