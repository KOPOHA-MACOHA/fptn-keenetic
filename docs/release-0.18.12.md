# Панель и служба 0.18.12

Проверены внешние команды рабочего установщика, службы и панели. Bootstrap
теперь устанавливает отсутствующие nice, nohup, base64, stty, stat, readlink,
mktemp, sha256sum, netstat, tar и gzip из Entware. IPK объявляет соответствующие
пакеты; базовые команды прошивки проверяются перед развёртыванием FPTN.
Добавлена ранняя проверка необходимых команд короткого загрузчика.

Тесты сверяют зависимости bootstrap/IPK и команды preflight, воспроизводят
отсутствие утилит без доступа к богатому PATH среды CI. IPv6-инструменты
по-прежнему требуются только для явно включённого IPv6. Дополнительные фоновые
процессы не добавлены. Клиент 0.8.1 и SDK не пересобираются.
