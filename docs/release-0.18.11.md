# Панель и служба 0.18.11

Исправлена установка на системах без команды `timeout`, в том числе
зарегистрированный случай Giga KN-1012 с KeeneticOS 5.2 Beta 3.
Bootstrap автоматически устанавливает `coreutils-timeout`, если команда
отсутствует, и проверяет её наличие перед запуском установщика.
Пакет IPK также явно зависит от `coreutils-timeout`.

Клиент 0.8.1 и его зависимости не пересобираются. Работа на конкретном
устройстве требует отдельной проверки; этот фикс устраняет показанную
ошибку отсутствующей команды и не подтверждает все последующие этапы установки.
