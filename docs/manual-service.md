# Архив: ранняя служба с собственной IPv4/CIDR-маршрутизацией

Этот документ описывает устаревший экспериментальный вариант и не является
инструкцией установки текущего выпуска. Используйте [единый установщик](install.md)
и [интеграцию с OpkgTun0](native-interface.md).

Ранний вариант использовал временный интерфейс `fptn0`, список `/opt/etc/fptn/cidrs`,
таблицу маршрутизации 30091, протокол 186 и правила приоритета 61 для LAN `br0`.
Цепочки `FPTN_KN_F` и `FPTN_KN_N` обслуживали FORWARD и MASQUERADE.
Эта собственная маршрутизация не используется и не развивается в native-службе.

При миграции установленный старый менеджер нужно остановить до замены,
чтобы он удалил принадлежащие ему записи. Его `recover` предназначен для очистки
остаточного состояния после завершения процесса; неизвестные и чужие записи
не должны удаляться вручную без проверки принадлежности.

Текущая native-служба использует `OpkgTun0`, сохраняет внешнюю маршрутизацию
при остановке и не читает прежний файл `cidrs`. Настройки и резервные копии
хранятся в `/opt/etc/fptn`; токены и пароли не включаются в отчёты об ошибках.
