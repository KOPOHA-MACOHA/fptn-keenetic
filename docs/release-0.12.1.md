# Панель 0.12.1

Исправлено мигание формы входа при обновлении страницы с действующей сессией.
HTML скрывает форму до загрузки JavaScript и решения о состоянии авторизации.
Во время проверки показывается нейтральное состояние загрузки.

Сохранённая сессия проверяется через авторизованный status. При успехе сразу
открывается панель; форма входа не появляется. Без сессии или после ответа 401
форма показывается после получения актуальных настроек входа. Ошибка сети
не удаляет сохранённый ключ: показывается ошибка и кнопка повтора.
Фоновый опрос статуса не стартует до восстановления авторизованной панели.

Проверены начальный HTML и отложенные ответы API для действующей/истёкшей/
отсутствующей сессии и сетевой ошибки с повтором. Изменений клиента, маршрутов,
службы VPN и большого установщика с нуля в этом выпуске нет.
