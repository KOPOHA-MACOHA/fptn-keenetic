# Панель и служба 0.13.0

Один путь для установки с нуля и обновления, без старых тестовых папок:
проверка платформы Entware, закреплённые клиент и Brotli, лицензии, временная
загрузка с проверкой SHA256 и полный самостоятельный архив выпуска.
Bootstrap ставит только недостающие системные пакеты Entware.

После установки токен и сервер задаются в браузере. До настройки кнопка запуска
недоступна. Собственный OpkgTun0 создаётся и сохраняется отдельной кнопкой;
DNS, маршруты, firewall и общий выход в интернет остаются у Keenetic.

Обычное обновление сохраняет настройки и работающий клиент, если ELF не изменился.
Добавлено `fptnctl uninstall`: удаляются только файлы программы и панели, а
конфигурация, учётные данные, firmware-интерфейс и маршруты остаются.

[Установка, обновление, удаление и ограничения](install.md).
На момент этого выпуска доступна платформа mipsel MIPS32r2 soft-float.
Клиент 0.4.0 основан на FPTN 0.4.6. Текущий перечень архитектур и границы
проверки находятся в [документации платформ](platforms.md).
