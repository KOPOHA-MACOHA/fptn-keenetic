### Исправление автозапуска после перезагрузки

Служба могла не запуститься после перезагрузки роутера: каталог состояния в `/opt/var/run` сохранялся, и запуск требовал ручного `fptnctl recover`. Теперь состояние предыдущей загрузки определяется по boot ID ядра, журналы сохраняются, затем выполняется обычный запуск с настроенной политикой серверов.

PID текущей загрузки и неоднозначное состояние автоматически не удаляются. Старые PID не используются для отправки сигналов. Маршруты, DNS и настройки интерфейса не меняются.

Версия панели и службы — 0.18.6; клиент остаётся 0.8.0. Пересборка клиента и зависимостей не требуется.
