Сервер и токен

          
          

          
При обрыве — автовыбор: сначала избранные, затем остальные. Выбирается сервер с наименьшим временем успешного входа.

          
Избранные и исключения

          
★ — избранный, × — исключённый. Исключённые серверы не проверяются. Списки применятся после сохранения.

02
Параметры подключения

          

            
            
            
            

              
              
              
              
Автоподбор появится в отдельном обновлении. Сейчас укажите домен вручную.

            

            
Резервные методы для избранных
              
              
Сначала текущие настройки, затем разрешённые запасные методы на избранных, потом остальные серверы. Известное устойчивое сочетание пробуется первым. Исключённые серверы не проверяются.

              

                
                
                
                
                
                
Для 1–8 разрешённых избранных. После лимита — обычный выбор остальных серверов. Обфускация проверяется автоматически; двойной/тройной туннель не меняется. Это реальные попытки FPTN, а не массовый поиск доменов.

              

            

            
Дополнительные параметры
              
              
Требует IPv6 в локальной сети Keenetic, IPv6 NAT в ядре, ip6tables Entware и MTU от 1280. Добавляет адрес только интерфейсу FPTN и отдельное правило NAT66 для направленного в него трафика. Доменные и CIDR-маршруты IPv6 задаются в Keenetic. По умолчанию выключено.

              
              

              
«Как в Keenetic» использует текущее значение OpkgTun0. Значение по умолчанию оригинального FPTN — 1420. Вручную можно задать 576–65535 только для интерфейса FPTN.

              
              
Необязательно: системное имя, например eth2.2. Пусто — обычное подключение к интернету. Поддерживаются Ethernet и PPPoE без отдельного шлюза. При отсутствии выбранного подключения служба ждёт его восстановления. В автоматическом режиме следует смене WAN.

            

            
            
Сохранение не запускает остановленную службу.
