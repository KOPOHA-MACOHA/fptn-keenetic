# Панель и служба 0.11.1

Исправлено определение файла клиента на минимальном BusyBox без stat -c.
Используется общий для GNU stat и BusyBox режим stat -L -t, с разбором
метаданных после полного имени файла. Время последнего доступа исключено:
выполнение --help не должно само инвалидировать кэш. Проверяются замена
бинарника с той же версией, имена с пробелами и некорректный вывод stat.
Рабочие файлы при предыдущей ошибке preflight не изменялись.
Клиент 0.4.0 и зависимости не пересобираются.
