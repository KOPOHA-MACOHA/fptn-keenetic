# Панель и служба 0.11.0

Возможности установленного клиента становятся общим источником для панели,
обычной валидации и резервных методов. Список браузеров, версий SNI-профилей и
стратегий больше не копируется в JavaScript, shell-валидатор и PHP-валидатор.

- Список извлекается из --help; выполняются только --help и --version, без токена.
- Кэш привязан к файлу бинарника (устройство/inode/размер/mtime/ctime), а не только
  к строке версии. SHA-256 вычисляется при обновлении кэша, а не при каждом чтении.
- Новые профили/браузеры ожидаемого формата появляются автоматически. Если формат
  help несовместим, валидация прекращается с ошибкой, старый список не подставляется.
- В резервных методах два выпадающих списка вместо четырёх фиксированных галочек.
  Существующие выбранные профили сохраняются. Удалённый профиль можно удалить
  из списка; при выключенном подборе он не мешает сохранять обычные настройки.
- Установщик проверяет возможности целевого бинарника до изменения файлов,
  затем повторно проверяет настройки и включённые резервные профили после установки.
- Успешная компиляция нового оригинального клиента по-прежнему требует проверки
  совместимости: новый формат метода/стратегии может потребовать адаптации парсера.

Новый PHP/Python/openssl на роутере не нужен. Используется уже имеющийся PHP
для прежних функций панели; само обнаружение работает через sh/awk/jq и BusyBox.
Клиент 0.4.0, протокол и зависимости не пересобираются. Совместимость с конкретной моделью не следует из одних только host-тестов.
